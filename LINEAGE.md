# 🧬 Desktopians Lineage Chain

Desktopians is passed hand-to-hand like a torch. **Every time you fork it, you
add one line below.** Never delete an existing line — only add yours under the
last one. This makes an unbroken, blockchain-style chain: anyone can trace any
version all the way back to Generation 0.

## The Rule (one line per fork)

When you fork, copy the format and append your row:

`Gen N | YourName | link-to-your-repo | forked-from: PreviousName (Gen N-1) | date`

Each entry references the one directly above it — so Gen 10 points to Gen 9,
which points to Gen 8 ... all the way to Gen 0. Break the chain = break the rule.
